# Бот расписания СибГУ

Расписание живьём берётся с сайта вуза `timetable.pallada.sibsau.ru`:
группа ищется через эндпоинт `/ajax/search_schedule`, расписание парсится
со страницы `/timetable/group/<id>`. Внутри бота расписание больше не хранится.

## Команды

- `/group БПА24-01` — задать или сменить группу для текущего чата, топика или ЛС
- `/status` — что сейчас настроено для этого чата
- `/today`, `/tomorrow`, `/week`, `/day <день>` — расписание настроенной группы
- `/setchat [chat_id [thread_id]]` — включить автоотправку для этого чата
- `/disable_auto` — выключить автоотправку
- `/sendtext <текст>` — отправить текст во все чаты, которые вы настроили
- `/exams`, `/nearexam`, `/setexam` — напоминания об экзаменах
- `/now` — проверка, что бот отвечает

## Автоотправка

На одно «место» (чат/топик/ЛС) — одна группа. После последней пары дня бот
публикует расписание на завтра. Если сегодня пар нет, время берётся по
ближайшему учебному дню. Публикации разных чатов идут каждая в своё время.

## Запуск

Переменная окружения: `BOT_TOKEN`.

В группах бот получает обычный текст только если у него выключен privacy mode
(@BotFather → `/setprivacy` → Disable) либо пользователь отвечает на сообщение
бота. Команда `/group` работает всегда.

## Источник расписания

По умолчанию бот ходит на сайт вуза через прокси на своём хостинге:

```
https://hekkeyne.ru/timetable-api/timetable.php
```

Это нужно потому, что с Railway сайт вуза недоступен (соединение по 443 порту
отваливается по таймауту), а SpaceWeb до него дотягивается.

Сам прокси — файл `hosting/timetable.php`, лежит в `public_html/timetable-api/`.
Он умеет три вещи:

- `?action=search&q=БПА24` — поиск групп через `/ajax/search_schedule`;
- `?action=resolve&id=1157&q=БПА24-01` — id страницы расписания (`page_id`);
- `?action=page&id=13922` — HTML страницы группы.

Переопределение через переменные окружения:

- `SCHEDULE_PROXY` — другой адрес прокси, либо `direct` чтобы ходить на сайт
  напрямую;
- `SCHEDULE_PROXY_TOKEN` — если в начале `timetable.php` задан `TOKEN`.
